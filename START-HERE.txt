my tier. 실행 방법
=================

1. ZIP 파일을 먼저 모두 압축 해제하세요.
2. 사용하는 운영체제의 파일을 실행하세요.

   Windows 10/11 : START-Windows.bat 더블클릭
   macOS        : START-macOS.command 더블클릭
   Linux        : START-Linux.sh 실행
                  또는 터미널에서 bash START-Linux.sh

첫 실행에는 인터넷 연결이 필요합니다. 필요한 Node.js와 앱 의존성을
자동으로 준비합니다. 관리자 권한이나 별도 API 키는 필요하지 않습니다.
Node.js를 다운로드하면 공식 SHA-256 체크섬을 검증합니다.

준비가 끝나면 기본 브라우저에서 앱이 자동으로 열립니다.
브라우저가 열리지 않으면 실행 창의 Ready: 뒤에 있는 주소를 복사하세요.
앱을 사용하는 동안 실행 창을 열어 두세요. Ctrl+C로 종료할 수 있습니다.

가수 사진과 곡 검색에도 인터넷 연결이 필요합니다.
브라우저에 저장한 티어와 대표곡은 같은 브라우저에서 복원됩니다.
폴더의 .runtime 파일을 유지하면 다음 실행에서도 같은 주소를 사용합니다.
가수·곡 선택을 따로 보관하려면 앱의 '내 티어 저장' 메뉴를 이용하세요.

macOS에서 권한이 없다는 메시지가 표시되면 터미널에서
bash START-macOS.command 명령으로 실행할 수 있습니다.
